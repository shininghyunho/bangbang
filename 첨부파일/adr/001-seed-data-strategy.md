# [ADR-001] 재귀 CTE를 활용한 대용량 시드 데이터 생성 전략

## 1. Summary
- 결정: 외부 스크립트(JS) 및 CSV 파일 의존성을 제거하고, 재귀 CTE(Recursive Common Table Expression)를 활용한 단일 SQL 문으로 약 300만 건의 시드 데이터 생성 환경 구축
- 날짜: 2026-04-29

## 2. Context (배경)
- 문제 상황: 
  - 대용량 검색 성능 테스트를 위해 약 300만 건의 데이터가 반복적으로 필요함. 
  - 기존에는 JS 스크립트로 CSV를 생성한 후 `LOAD DATA`로 삽입했으나, 파일 I/O 대기 시간이 길고 외부 런타임 환경(Node.js)에 의존적인 문제 발생.
- 요구 사항 및 제약: 별도의 도구 설치 없이 DB 클라이언트만 접속 가능한 환경에서도 즉시 동일한 규모의 테스트 데이터를 재현할 수 있어야 함.

## 3. Alternatives (대안 목록)
- 대안 A: 외부 스크립트(Node.js) + CSV Bulk Load
  - 별도 언어 런타임 및 파일 시스템 쓰기 권한 필요.
  - 데이터 생성(Script) → 저장(CSV) → 로드(DB)의 3단계 공정으로 인한 비효율.
- 대안 B (선택): 재귀 CTE 기반 단일 SQL 생성
  - 별도 인프라 의존성 없이 순수 SQL만으로 데이터 정의 및 삽입 가능.
  - 선언적(Declarative) 코드로 데이터 생성 규칙 가독성 확보.

| 비교 항목 | 대안 A (JS + CSV) | 대안 B (SQL CTE - 선택) |
| :--- | :--- | :--- |
| 환경 의존성 | 언어 런타임, 파일 시스템 필요 | DB 엔진만으로 실행 가능 |
| 처리 단계 | 3단계 (파일 I/O 포함) | 1단계 (In-memory 생성) |
| 재현 편의성 | 낮음 (스크립트 공유 필요) | 높음 (SQL 문 공유) |

## 4. Decision (결정)
- 결론: 재귀 CTE 및 Cross Join을 활용한 SQL 기반 생성 방식 채택
- 근거: 
  - 프로젝트 환경이 Docker로 격리되어 있으므로, 외부 의존성을 최소화하는 것이 환경 구성의 단순화에 직결됨.
  - 메모리 내에서 데이터를 생성하므로 파일 I/O가 발생하지 않아 데이터 준비 시간이 크게 단축됨.

## 5. Trade-offs (Pros/Cons)
- Pros (얻은 것)
  - 생성 시간 단축: 기존 방식(약 5분) 대비 생성 및 삽입 시간이 약 30초로 단축됨.
  - 환경 독립성: SQL 파일 하나만으로 별도의 런타임 설정 없이 대용량 테스트 환경 구축 가능.
  - 유지보수 용이: 데이터 생성 규칙 변경 시 SQL 코드 수정만으로 즉시 반영됨.
- Cons (포기한 것)
  - 엔진 설정 의존: `cte_max_recursion_depth`와 같은 DB 시스템 변수 조절이 선행되어야 함.
  - 문법적 제약: 복잡한 랜덤 데이터 생성 시 프로그래밍 언어(JS) 대비 SQL 표현력의 한계가 존재함.

## 6. Retrospective (회고)

처음에는 대량 데이터 삽입이라고 하면 당연히 애플리케이션 코드(JS 스크립트)로 데이터를 만들고, CSV로 내보낸 뒤, `LOAD DATA`로 DB에 밀어 넣는 방식만 떠올렸다. 이전 프로젝트에서도 항상 그렇게 해왔기 때문이다.

그런데 MySQL 공식 문서를 읽으며 재귀 CTE라는 기능을 알게 되었고, 굳이 외부 스크립트를 거치지 않아도 SQL 자체만으로 대량의 데이터를 생성할 수 있다는 것을 확인했다. 특히 숙소 ID 목록과 날짜 목록을 각각 재귀 CTE로 만든 뒤 Cross Join으로 조합하면, 재귀 깊이는 수천 회 수준으로 유지하면서도 결과적으로 수백만 건의 행을 만들어낼 수 있었다.

결과적으로 기존 방식(약 5분)에서 약 30초로 데이터 생성 시간이 줄었고, Docker 컨테이너 기동 시 `init.sql` 하나만 마운트하면 별도 설정 없이 환경이 구성되는 구조를 만들 수 있었다. 관습적으로 써오던 방식을 의심하지 않았다면 이런 개선은 이루어지지 않았을 것이다. 도구에 대한 이해가 깊어질수록 선택지가 넓어진다는 것을 체감한 경험이었다.
